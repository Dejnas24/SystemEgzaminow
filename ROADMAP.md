# System Egzaminów – Roadmap

The project is being developed in stages. The roadmap below presents the main
directions for the application's development and may change as the project evolves.

## v0.9.0-beta – Current version

The first public beta release of the application.

It includes the core features of the examination system, including:

- support for administrator, teacher and student roles,
- user management,
- creating questions and answers,
- creating and assigning tests,
- support for single-choice, multiple-choice and open-ended questions,
- taking tests by students,
- automatic calculation of test results,
- grading scales,
- logging events related to users and test-taking,
- exporting selected data to Excel and PDF.

## v1.0 – Stable WPF release

The goal of version 1.0 is to complete and stabilize the current WPF application.

Planned features and improvements:

- development of the test results module,
- development of test-solving reports based on recorded test activity,
- improved randomization of questions and answers,
- improved navigation between question and answer creation and editing,
- extension of PDF reports to include submitted answers,
- display of information about the currently logged-in user,
- addition of an About section,
- fixing detected bugs,
- further application testing.

## Future development

After the stable version 1.0 is released, further development directions may include:

- extending the architecture with an API,
- data synchronization,
- development of user settings and interface personalization,
- support for groups, classes, school years and academic years,
- further development of reporting features,
- accessibility improvements,
- a mobile and cross-platform application using .NET MAUI,
- a web application,
- multilingual support,
- development of features supported by artificial intelligence.

## Long-term vision

The long-term direction of the project is the possibility of transforming
System Egzaminów into a larger educational platform for schools,
universities and training organizations.

The scope and order of future features are not final and may change.
